# Skill pessoal Violeta PRD

## Papel

A skill `violeta-prd` aplica o fluxo Violeta diretamente no Codex antes de a aplicação estar pronta. Ela cria, revisa e atualiza PRDs/SDDs, consulta fontes autorizadas, faz perguntas adaptativas, estrutura gates e valida evidências.

## Versão inicial

- funciona com ou sem GitHub e Linear;
- registra limites de autorização antes de agir;
- classifica fatos, decisões, propostas, hipóteses e pendências;
- dimensiona PRDs como essenciais, técnicos, críticos ou institucionais;
- incorpora TestSprite como evidência limitada ao ambiente executado;
- inclui validador estrutural determinístico;
- não inicia implementação automaticamente.

## Evolução

1. Usar a skill em PRDs reais e anotar perguntas irrelevantes ou seções ausentes.
2. Criar fixtures anonimizadas e evals.
3. Integrar os schemas estruturados da aplicação.
4. Usar conectores Violeta para GitHub, Linear e TestSprite.
5. Gerar e revisar bases de agentes por projeto.
6. Medir tempo economizado, cobertura de lacunas e correções humanas.

## Fronteira

A skill define o procedimento. A aplicação Violeta fornecerá interface, persistência, conectores, schemas e relatórios. Nenhuma delas substitui a aprovação humana.
